# Security Policy

## Supported Version

The currently documented release is Poker Tournament Manager v1.1.1.

## Reporting a Security Issue

Do not publish credentials, personal data, exploit details, or other sensitive information in a public issue.

Use GitHub's private vulnerability-reporting feature if it is enabled for this repository. If private reporting is unavailable, contact the project owner through the professional contact method listed on the owner's GitHub profile or portfolio.

Please include:

- A clear description of the issue
- The affected version
- Reproduction steps
- Expected and actual behavior
- The practical impact

## Public Repository Scope

This repository is a curated portfolio case study and does not contain production databases, user records, private source documents, credentials, or the full private development archive.
